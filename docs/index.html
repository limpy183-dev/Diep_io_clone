How it is put together

Three ideas carry all thirty-eight.

A mode is a table row

Every mode is one entry in GAMEMODES plus, if it needs one, a MODE_LOGIC entry with init / tick / onSpawn / onTankDeath / reset / botGoal. Nothing forks the base game.

Rule modes are one constant

Instagib, Vampire, Ice Rink and Blood Money change a single number that the whole simulation already reads — damage, regeneration, friction, XP share — through one Game.rule() lookup. The consequences cascade for free, which is why they feel like different games rather than different arithmetic.

Every objective mode teaches the bots

A mode without a botGoal plays fine online and looks broken offline, with the bots walking past the payload for ten minutes. All thirty-eight ship one. The Juggernaut goes further and registers itself as the arena bounty, so bot target scoring outbids everything else and they gang up on it instead of farming.

Thumbnails are drawn by js/modefx.js — the same painters the in-game Mode Lab uses, loaded directly rather than exported as images. Mode text comes from docs/modes.json, regenerated from the source of truth in js/modes-extra.js.
